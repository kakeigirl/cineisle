# 映屿 CineIsle v0.4.2 用户反馈修复版

本版根据真实用户反馈修复三类问题：MCP 截图看不到真实图片、字幕导入 0 条、影院播放十秒后卡住。

## 1. MCP 截图通道

### 问题
用户截图已上传，服务端也收到图片，但 MCP 平台可能把图片 dataUrl 转成 `mcp_img_xxx.jpg` 占位符，模型无法读取真实像素。

### 改动
- 截图上传后生成可访问的 `image_url / imageUrl / url`。
- 新增签名图片路由：`/api/rooms/:id/frames/:frameId.jpg`。
- MCP 返回截图元数据时保留 `image_url`、`ocrText`、`extractedText`、`fallbackText`。
- 新增 MCP 工具 `get_screenshot_text`。
- `get_viewing_context` 返回 `images` 与 `ocr_results` 兜底字段。

### 说明
当前版本没有引入重量级本地 OCR 引擎。PWA 手动截帧会把当前字幕/最近字幕作为 `ocrText` 兜底；Android 低频截图会返回可访问图片地址。若模型端仍无法读图，可让用户把截图直接发到对话里临时绕过。

## 2. 字幕导入 0 条

### 问题
标准 SRT 文件在手机预览正常，但导入后提示 0 条。

### 改动
- PWA 字幕读取改为 `ArrayBuffer + TextDecoder` 多编码尝试。
- Android 字幕读取增强 UTF-8、UTF-8 BOM、GB18030、UTF-16LE、UTF-16BE。
- 统一换行，去除 BOM、零宽字符、特殊空格。
- SRT/VTT 解析改为逐行扫描时间轴，不再只依赖空行分块。
- 支持逗号毫秒与点号毫秒。
- 导入失败时区分文件为空、未匹配时间轴、匹配时间轴但正文为空。

## 3. 播放十秒后卡住

### 问题
用户反馈影院播放约 10 秒后卡住，偶尔又能继续几秒。

### 改动
- PWA 记录播放器事件：`loadedmetadata`、`canplay`、`waiting`、`stalled`、`error`、`timeupdate`、`progress`。
- PWA 对 HTTP(S) 片源尝试 `Range: bytes=0-1` 检测。
- 同步逻辑加入本地操作保护：用户刚刚手动播放/暂停/拖动时，不立刻被旧房间状态回拉。
- Android VideoView 增加错误/缓冲信息上报。
- 后端保存 `playbackDebug` 并提供 `/api/rooms/:id/playback-debug`。
- 新增 MCP 工具 `get_playback_debug`。
