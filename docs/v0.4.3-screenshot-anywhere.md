# v0.4.3 截图前台限制调整

## 变更

- 移除 Android 无障碍截图上传前的「映屿必须在前台」判断。
- 自动低频截图和「给 AI 看一眼」现在会截取当前屏幕。
- 本地按钮提示改为：请求后停留在想给 AI 看的画面。
- README 与 MCP `request_screenshot` 描述同步更新。

## 保留的安全门槛

- 仍然需要用户在 App 内打开自动截图/发起看一眼。
- 仍然需要系统无障碍截图权限。
- 仍然使用房间 Token 校验上传接口。

## 注意

因为现在不再要求映屿在前台，截图内容会是手机当前屏幕。请只在愿意让 AI 看见当前画面时开启或请求截图。
